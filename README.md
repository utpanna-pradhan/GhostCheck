
# GhostCheck

### Don't waste an application. Check the job first.

GhostCheck is an AI-powered job posting analysis platform
that helps job seekers identify potential ghost job risk signals.

## Tech Stack

- Next.js
- TypeScript
- Tailwind CSS
- Node.js
- Express
- PostgreSQL (planned)
- Prisma (planned)
- AI integration (planned)

## Project Structure

ghostcheck/
├── frontend/
└── backend/

## Local Development

### Frontend

cd frontend
npm install
npm run dev

### Backend

cd backend
npm install
npm run dev
